1. 数据流对比

旧（v1，当前 step4.py）

title ↓ score_all_categories(title) ↓ Σ keyword·weight (8 cat) ↓ top1 ~= top2 ? ├─ yes → llm_classify_single └─ no → use top1 ↓ 栏目内多篇 → 取最高分 1 篇 ↓ top-10 by score
特性：纯关键词，长尾词易漏；LLM 仅做仲裁，1 题 1 调；无重要性/时效性维度

新（v2，本次方案）

title + source ↓ score_signals(title, source) ├─ call_llm("column-score") → JSON └─ fallback → 旧关键词分数 ↓ {relevance{8 cat}, importance, timeliness} ↓ aggregate = relev·(0.5 + 0.3·imp/10 + 0.2·time/10) ↓ 归属栏目 = argmax(relevance) 栏目内排序 = aggregate desc ↓ top-10
特性：语义打分 + 显式重要性/时效性；关键词层保留；JSON Schema 强约束

2. LLM I/O 样例

Prompt（节选）

你是中国正面新闻编辑。对下面新闻标题就 8 个栏目分别打分：
栏目：🔬 世界性科研突破 / 🌾 农业 / 🤝 扶贫 / ⚡ 能源 / 🏥 医疗 / 🚀 科技 / 🧱 材料 / 🎖️ 军事

输出 JSON：
{
  "relevance": {"🔬 世界性科研突破": 0-10, ...8 项},
  "importance": 0-10,     // 该新闻自身重要性
  "timeliness": 0-10      // 时效/突发性
}

标题: 中科院团队首次在常温下实现拓扑超导体
来源: news.cas.cn

Output

{
  "relevance": {
    "🔬 世界性科研突破": 9,
    "🌾 农业": 0, "🤝 扶贫": 0,
    "⚡ 能源": 2, "🏥 医疗": 0,
    "🚀 科技": 7, "🧱 材料": 5,
    "🎖️ 军事": 0
  },
  "importance": 8,
  "timeliness": 6
}
argmax(relevance) → 🔬 世界性科研突破
aggregate = 9 × (0.5 + 0.24 + 0.12) = 9 × 0.86 ≈ 7.74
