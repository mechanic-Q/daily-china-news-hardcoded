## E2E User Flow

```
用户输入 run_all.sh (--date)
  → step1_3: 7信源并发采集 (aiohttp)
  → step4: 8栏目分类 + 涉华过滤 + 优先级排序
  → step6: 5层策略链提取正文
  → step7: MiniMax M2.7 LLM 逐条摘要
```

所有 flow 完整无断裂。

## Tech Debt

非阻塞性改进项：

1. **Summary 文本**: 目前为自动拼接各条摘要首句，未来可由 LLM 生成更自然的多句概览
2. **PNG 文件名期数**: 中文序数对脚本处理不友好，可加 `--issue-numeric` 选项
3. **chromium 路径**: 硬编码 `/snap/bin/chromium`，可改为环境变量 `CHROMIUM_PATH`
