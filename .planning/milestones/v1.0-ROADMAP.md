## Overview

将 daily-china-news Hermes skill（AI 驱动新闻采集流程）改造成确定性 Python 脚本管道。
从7个中国权威信源自动采集→分类筛选→正文提取→LLM摘要→报纸渲染，生成可视化 PNG 报纸。
