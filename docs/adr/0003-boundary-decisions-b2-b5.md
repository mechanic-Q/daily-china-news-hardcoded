# ADR-0003:分类开放边界 B2-B5 定案

## Status
Accepted

## Date
2026-07-25

## Context
ADR-0002 列出四个开放边界(B2/B3/B4/B5)待 grill。本 ADR 记录 2026-07-25 grilling 会话对四者的定案,作为 ADR-0001/0002 的补充判据。定案后 B2-B5 不再"开放",可供后续 spec 实现。

## Decision

### B2:科技 vs 世突(B2 单国全链)-- "世界前沿难度"落地
B2 准入 = 同时满足:
1. **前沿域白名单**(命中其一):半导体/集成(光刻机、EUV、先进制程、刻蚀机、EDA、AI 芯片、存储芯片)、大飞机/航空(大飞机、航空发动机、涡扇、C919/C929)、算力/大模型(大模型、算力、GPU、训练集群、光模块)、核能(核聚变、人造太阳、第四代核电、高温气冷堆)、量子(量子计算机、量子通信、量子芯片)、高端制造(高铁、数控机床、工业软件、工业机器人)、深空航天(空间站、探月、探火、重型运载)、商业航天、新能源电池、高端医疗、**农业生物前沿(合成生物、育种、二氧化碳造淀粉、基因编辑、人工合成)**。
2. **单国全链/国产化信号**(命中其一):全产业链 / 规模化量产 / 国产化 / 自主可控 / 打破封锁 / 不再依赖 / 国产替代。
3. **新突破里程碑**(命中其一):首次 / 首例 / 世界首 / 全球首 / 攻克 / 填补空白 / 研制成功 / 颠覆 / 下线(首台)/ 投产(首条)/ 实现量产(首次)。
4. **¬例行**:第 N 架 / 例行发射 / 常规迭代 / 年度交付数。

**"突破"歧义排除:** "突破 X 万吨/亩"是超数量,非技术突破;"突破"单独不作信号,须配"首次/首例/攻克"或作"重大突破/技术突破"。

**杂交水稻切分:** 例行(种植/推广/制种/面积)-> 🌾农业;新突破(一系1号、世界首例、克隆效率 99%)-> 🔬世突(A 原型,靠"首次/首例"命中)。二氧化碳造淀粉同理(世界首例人工合成 -> A)。

### B3:外交 vs 军事 -- 纯政治剔除
- **纯政治**(礼宾词:会见/访问/出席/接见/晤/磋商/峰会/联合声明/公报,且**不命中任何行业关键词**)-> 剔除。
- **政治影响行业**(外交事件 + 行业实质:签能源协议、联合军演、农业合作)-> 留该行业。
- 机制:命中礼宾词且不命中任何行业关键词 -> 剔除;命中行业词的走正常分类。
- 军事栏保持纯军事(军演/装备/部队/国防建设/官兵),外交会见不入军事。
- 验证:"泰国总理会见董军"(礼宾+无行业词)-> 剔除;"中俄签署能源合作协议"(能源词)-> 留能源;"中俄联合军演"(军演词)-> 留军事;"习近平出席 G20 发言"(礼宾+无行业词)-> 剔除。

### B4:扶贫 vs 乡村振兴 -- 保留标签扩词
- 栏名"🤝扶贫"不变(零结构改动)。
- 词表扩:乡村振兴 / 巩固脱贫 / 乡村产业 / 农村人居 / 和美乡村 / 乡村建设。

### B5:政策/规划/权威发布 -- 按具体性分
- **剔除**(展望/口号):有较好基础 / 稳中向好 / 稳步推进 / 总体平稳 / 稳定 / 扩量提质 / 可靠替代 / 形势(好)/ 基础牢。
- **保留**(具体行动):印发 / 实施 / 启动 / 部署 + 具体工程/规划/计划名。
- 验证:"夺取全年粮食丰收有较好基础"(展望)-> 剔;"进一步实现扩量提质可靠替代"(口号)-> 剔;"印发可再生能源十五五规划部署 X 工程"(具体行动)-> 留能源。

## Provenance / 溯源
- 源于 2026-07-25 grilling 会话(紧接 ADR-0001/0002 之后),项目所有者与 AI 协同。
- 关键决策点:
  - B2 加"新突破里程碑"闸(防前沿域内例行量产混入);前沿域白名单扩至农业生物前沿(二氧化碳造淀粉/杂交水稻/合成生物)。
  - B3 不加外交栏,而是纯政治剔除(报纸不覆盖政治外交);带行业影响的留该行业。
  - B4 保留"扶贫"标签零结构改动,只扩乡村振兴词。
  - B5 按具体性分(展望/口号剔,具体行动留),非全过滤。

## Consequences
- B2-B5 不再开放,可供实现。后续 spec 应把这些边界修复纳入(更新 issue #33 的 Out-of-Scope,或出 follow-up spec)。
- ADR-0002 的"层 3 开放边界"相应标记为已解决(指向本 ADR)。
- 实现后更新 ADR-0001/0002 的 known gaps 状态。
- 前沿域白名单需维护(新前沿域出现时加)。
