# ADR-0002:跨栏目分类审计与全局病根

## Status
Accepted

## Date
2026-07-25

## Context
ADR-0001 定义了"世界性科研突破"判据。落地前,项目所有者要求审计其余 8 栏是否存在同类分类问题,若有则一并处理。本 ADR 记录审计结果,作为全栏目分类问题的溯源凭据。

审计证据:2026-07-25 第九十八期报纸 + `step4.py` 词表/逻辑。

## Decision
全栏目分类问题归为三层,按层统一处理(非逐栏重做定义):

### 层 1:全局病根(影响全部 9 栏)
- **G1 只看标题**:`score_all_categories(title)` 只用标题,正文信号丢失。A 原型"世界首例"常在正文。
- **G2 无 scope/quality 闸**:非科研/非本栏事件可被 LLM 硬塞,无规则拦截。典型:溃坝->世突、瓷都->材料。
- **G3 弱 LLM 独裁**:凡关键词未命中的条目,分类全靠 model:low 一锤,过判与漏判并存。

### 层 2:逐栏 gap(C1-C5)
- **C1 世突词表**:缺 B 原型词(卡脖子/断供/封锁/国产替代/自主可控/全产业链/规模化量产)+ 农业科研词(水稻/育种);"卫星/航天/火箭发射"过广,会误捕例行发射。
- **C2 AI 跨栏冲突**:DeepSeek 在 AI dict(weight5),但按 B2 应入世突。需世突 override 垂直栏。
- **C3 农业缺核心词**:无 水稻/杂交稻/育种/稻。
- **C4 扶贫词汇过时**:停留 2021 前(精准扶贫),缺"乡村振兴",栏位系统性留空。
- **C5 科技 dict 过宽**:经济/产业/发展/建设/项目 当万能 sink,跨栏渗血。

### 层 3:开放边界(已解决,见 ADR-0003)
- **B2 科技 vs 世突(B2 单国全链)**:前沿域白名单 + 新突破里程碑闸。见 ADR-0003。
- **B3 外交 vs 军事**:纯政治剔除(礼宾词且无行业词),政治影响行业留该行业。见 ADR-0003。
- **B4 扶贫 vs 乡村振兴**:保留"扶贫"标签 + 扩乡村振兴词。见 ADR-0003。
- **B5 政策/规划/权威发布**:展望/口号剔,具体行动留。见 ADR-0003。

## Provenance / 溯源
- 审计源于 2026-07-25 grilling 会话(紧接 ADR-0001 之后),项目所有者要求跨栏排查。
- 已解决边界:B1(农业 vs 世突 A 原型)由 ADR-0001 解决。

## Current algorithm(全栏目相关)
- `high_confidence_keyword_category()`(:455):词表得分 ≥6 且领先 ≥3 才走关键词路径,否则 LLM。
- `assign_category()`(:556):世突 relevance ≥7 强制 override(仅世突有此待遇,其他栏无 override)。
- `build_classification_result()`(:626):关键词路径 -> LLM 批量 -> 关键词兜底,三段式。
- 分类全程只用 title 字段。

## Known gaps(为何各栏出问题)
见层 1/层 2。每个 gap 对应今天报纸的具体误判/漏判证据(见 Context)。

## Consequences
- 全栏目分类问题的验收标准 = ADR-0001(世突判据)+ 本 ADR(全局病根 + 逐栏 gap + 开放边界)。
- 修复优先级:层 1(全局 G1/G2/G3)一次修全栏受益 -> 层 2(逐栏词表)-> 层 3(开放边界 grill 后定)。
- 任何栏目再出误判/漏判,按"现象 -> 本 ADR gap 清单 -> 命中 -> 修"溯源。
- B2-B5 已解决,见 ADR-0003。
