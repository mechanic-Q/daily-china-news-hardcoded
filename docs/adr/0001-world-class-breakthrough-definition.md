# ADR-0001:"世界性科研突破"栏目的分类判据

## Status
Accepted

## Date
2026-07-25

## Context
2026-07-25 第九十八期报纸出现两处分类争议:
1. **误判(false positive)**:"国务院成立广西南宁横州市六蓝水库'7·6'溃坝灾害调查评估组"被归入"🔬 世界性科研突破"。灾害调查非科研、非突破。
2. **漏判(false negative)**:"我国杂交水稻育种科研取得重要进展"(一系法杂交水稻"一系1号",克隆效率99%,发《生命》期刊,世界首例)被归入"🌾 农业"而未进世界性突破。

经 grilling 会话(2026-07-25)与项目所有者确认,确立"世界性突破"三原型准入判据(见 Decision)。

## Decision
"世界性科研突破"栏目准入 = 满足下列三原型之一(详见 `CONTEXT.md` 词条"世界性突破"):
- **原型 A · 人类突破**:世界首次/最前沿 + 同行评议 + 全人类首当其冲。
- **原型 B1 · 破封锁**:西方主动技术封锁/断供/出口管制 + 该突破打破封锁、实现国产替代。
- **原型 B2 · 单国全链**:单国全产业链整合 + 规模化量产 + 世界前沿难度(共用门槛)。

明确排除:灾害调查/响应、纯市场追赶(无封锁且非单国全链前沿)、例行工程。
编辑视角:本报以中国自身宣传为立场,A 与 B1/B2 并列准入。

## Provenance / 溯源
- 判据源于 2026-07-25 grilling 会话(项目所有者与 AI 协同),非凭空生成。
- 关键决策点:
  1. #1"世界首次"仅为原型 A 的属性,**非全局门槛**(否则 B1/B2 失效)。
  2. B 必须有"硬封锁"(B1)或"单国全链+前沿难度"(B2),**纯市场追赶/规模化量产不够**。
  3. "世界前沿难度"是 B2 的防吸干闸(防世界性突破栏吸空科技/材料/能源)。

## Current algorithm & known gaps(为何会出现本次误判/漏判)
`step4.py` 当前实现:
- `assign_category()`(:556):LLM 给"世界性科研突破"relevance ≥ 7(`WORLD_CLASS_THRESHOLD`)即强制吸入,压过所有栏目。
- `CATEGORY_KEYWORDS['🔬 世界性科研突破']`(:378):仅含诺贝尔/量子/基因/航天/考古/发现/突破等基础科研词。
- 分类只看标题(`score_all_categories(title)`),不读正文。

**系统性漏洞(相对本判据):**
1. **B 原型零覆盖**:词表无 卡脖子/断供/封锁/国产替代/自主可控/全产业链/规模化量产 等 B1/B2 词汇 -> 所有破封锁/单国全链突破无法触发关键词路径,纯靠 LLM。
2. **农业科研词缺失**:无 水稻/育种/杂交 等 -> 杂交水稻这类 A 原型(经农业载体)也无法触发关键词,纯靠 LLM。
3. **只看标题**:A 原型"世界首例"信号常在正文(一系1号、99%克隆效率、发《生命》),标题可能仅"重要进展" -> 漏判。
4. **无非科研闸**:溃坝、政策、例行工程等非科研条目可被弱 LLM(model:low)误打 ≥7 -> 误判,无关键词或规则拦截。

## Consequences
- 本判据是"世界性突破"分类的**验收标准**。未来 step4 修复须以消除上述 4 个漏洞为目标,且不得违反排除项。
- 重新讨论"什么是世界性突破"时,先读本 ADR + `CONTEXT.md` 词条,从本判据出发增量修订,不从零开始。
- 算法再出误判/漏判时,按"现象 -> 本 ADR known gaps -> 命中哪条漏洞 -> 修"路径溯源。
- 跨栏目问题见 ADR-0002。
